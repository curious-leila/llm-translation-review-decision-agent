WHY THIS PRODUCT

为什么需要 Review Agent？

全人工审校成本高，
但让模型统一自动判断也不可靠。

前置评测发现，模型在不同风险 × 审校维度上的可靠性并不一致。因此产品目标不是最大化自动化，而是决定每条内容应该获得多少自动化权限。

为什么由 Rule 决定停止？

Stopping Ownership

Agent 可以探索未知证据，但不能决定自己已经足够可信。当证据满足充分条件，由 Rule 收回停止权，结束探索并进入最终判断。

模型判断 (Model Judgment)

MODEL

Agent 探索 (Agent Exploration)

AGENT

Rule 边界 (Rule Boundary)

RULE

输入校验、冲突与充分性边界、可靠性策略和最终路由

人工确认 (Human Confirmation)

HUMAN

确认抽样案例、高风险案例与未解决问题

Agent 可以决定下一步如何寻找证据，但不能决定自己是否获得最终放行。模型不能给自己发通行证。
