      WHY REVIEW AGENT

      全人工成本高，统一自动判断又不可靠。

      产品目标不是最大化自动化，而是给每条译文恰当的自动化权限。

      180 次人机双评
      61%术语 × 高风险一致率
      28 / 180原评测策略进入人工复核

      前置评测用于形成冻结路由策略，不是当前 Agent 上线后的效果指标。
